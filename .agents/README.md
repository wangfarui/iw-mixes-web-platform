# 联合工作区 Skill 入口

`skills/iw-feature-handoff` 是相对符号链接，目标为联合工作区根目录的 `skills/iw-feature-handoff/`。该 Skill 用于需求设计、开发交接和已确认方案的实施自验。

在包含三个业务仓库的 `iw-mixes_ai` 联合工作区中使用，唯一源由联合工作区维护，不在各仓库复制。单独克隆本仓库不会携带目标目录；需一并保留联合工作区 Skill 源，否则链接不可用。不要在联合工作区根初始化 Git。

入口文件存在、链接可解析与新会话实际可发现是不同状态。只在对应任务需要时调用，不代表所有任务自动执行该流程。
