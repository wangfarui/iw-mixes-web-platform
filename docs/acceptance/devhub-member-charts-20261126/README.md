# 指定成员分析图表验收

2026-11-26，按本次会话确认的需求，在团队代码的提交明细上方加入仓库提交频率和提交日历热力图。

仓库图使用提交明细接口返回的全量仓库汇总，热力图使用成员统计接口的每日汇总。两图共用所选团队、成员和日期范围，提交明细的筛选、排序和分页独立生效。

| 检查 | 结果 | 操作与观察 |
| --- | --- | --- |
| AC-01 布局 | 通过 | Chrome 以 1512 px 查看两图左右并排，以 760 px 查看两图上下排列。两种尺寸下提交明细均位于两图下方。[宽屏截图](desktop.png) · [窄屏截图](narrow.png) |
| AC-02 样式及统计 | 通过 | 仓库提交次数降序，默认显示前 10 项，可展开全部并收起。热力图日期、颜色和提示中的次数与夹具一致。零提交成员的仓库图显示空态，热力图显示范围内的零提交天。 |
| AC-03 范围与明细 | 通过 | 切换成员、本周与本月及团队时更新图表。明细翻页、排序、选择仓库和搜索关键词后，两图统计保持原值。点击图表不会触发明细筛选。 |
| AC-04 错误与回归 | 通过 | 初次仓库汇总加载失败时，热力图仍可查看，通过明细重试恢复仓库图。打开「我的代码」验证原仓库图仍展示前 10 项与展开入口。 |
| AC-05 自动化检查 | 通过 | `npm run type-check`、`npm run build`、`npm run test:zhaogang-code-stats-range` 和 `git diff --check` 均通过。 |

浏览器检查使用本地实际页面和隔离的 API 夹具。真实 CODING 登录态未联调，验收未写入业务数据。

在同一路由以隔离数据复验 13 个仓库的排行。1512 px 和 760 px 宽度均完整展示前 5 行，与本月热力图的内容高度相差约 5 px。验证了滚动到最后一个仓库、明细筛选保留滚动位置、切换成员后回到顶部，以及只有一个仓库和零提交时的显示。「我的代码」的展开入口通过回归检查。类型检查和生产构建通过。
