# 迭代工时输入验收

2026-11-19。Web 实际路由为本地 Vite 的 `/zhaogang/iterations/123`，使用隔离浏览器上下文和临时接口夹具。夹具拦截提交并返回可见错误，检查请求体，验证范围包括页面交互与前端请求。真实 CODING 写入未执行。

## 实现

登记工时默认取当前事项的预估工时减去页面已登记工时。差值小于等于 0 或缺少预估时填 1.0 小时。汇总与页面展示共用已登记工时口径，优先使用 CODING 汇总快照，缺失时使用本地审计合计。

登记使用工时和新增事项、新增子事项中的预估工时共用输入组件。有效值失焦后显示一位小数，最低 0.5 小时，按钮和键盘方向键步长为 0.5 小时。非法输入保留原文，显示错误并禁用提交。沿用小于 10000 小时的上限，最大可填半小时倍数为 9999.5 小时。
